Diabetic Retinopathy Detection Using ANN-RNN

Project Overview

This project presents a Dual-Stage ANN-RNN Hybrid Model for Automated Diabetic Retinopathy Detection.

The project aims to use deep learning techniques to analyze retinal images and help detect diabetic retinopathy.

The model works in two stages:

- ANN (Artificial Neural Network): Extracts important features from retinal images.
- RNN (Recurrent Neural Network): Analyzes the extracted features and identifies patterns related to diabetic retinopathy.

Objective

The main objective of this project is to develop an automated approach for diabetic retinopathy detection that can support early screening and reduce the time required for manual examination.

Key Features

- Automated diabetic retinopathy detection
- ANN-RNN hybrid model
- Retinal image analysis
- Deep learning-based approach
- Supports faster screening
